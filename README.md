# RoleLeaf Demo

English · [العربية](readme/ar.md) · [日本語](readme/ja.md) · [한국어](readme/ko.md) · [繁體中文](readme/zh-Hant.md)

RoleLeaf saves available character details, images, and conversations from Tipsy and Character.AI to your device.

[Download RoleLeaf Demo](https://quillharbor.github.io/roleleaf-demo/) · [Release files and checksums](https://github.com/quillharbor/roleleaf-demo/releases/tag/v0.5.13-demo)

## Android

1. On Android 8 or later, download the Demo APK. Open it, allow installation from your browser if prompted, then install RoleLeaf.
2. Open RoleLeaf and sign in to Tipsy or Character.AI. Tap **⋮ → Language** in the toolbar to change languages. Tap **Export** to start, or find **Open ZIP** under **⋮**.

## Desktop Chrome

1. On Chrome 111 or later, download and extract the ZIP to a folder you will keep.
2. Open `chrome://extensions`, turn on **Developer mode**, and choose **Load unpacked**. Select the `tipsy-exporter` folder containing `manifest.json`.
3. Pin RoleLeaf, refresh the source website, and open the extension popup. The language menu is in the popup.

## Export and update

Choose **Recent chats** or **My Characters**, select characters, and export. Keep the app or source tabs open until it finishes. Each character gets a separate ZIP. Extract it and open `README.html` to view the result. The report identifies missing fields and incomplete history. Exports can contain private conversations and images.

To update Android, install the new APK over the existing app. For Chrome, replace the contents of the same extension folder, reload the extension at `chrome://extensions`, and refresh the source website.
