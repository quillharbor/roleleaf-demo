# RoleLeaf

[English](../README.md) · [العربية](ar.md) · [日本語](ja.md) · 한국어 · [繁體中文](zh-Hant.md)

RoleLeaf는 Tipsy와 Character.AI에서 가져올 수 있는 캐릭터 정보, 이미지, 대화를 기기에 저장합니다.

[다운로드 및 설치 안내](https://quillharbor.github.io/roleleaf-demo/?lang=ko)

## Android

1. Android 8 이상 기기에서 데모 APK를 다운로드하세요.
2. APK를 여세요. 권한 요청이 표시되면 이 브라우저에서 알 수 없는 앱을 설치하도록 허용한 뒤 돌아와 설치하세요.
3. RoleLeaf를 열고 상단 도구 모음에서 **⋮ → 언어**를 선택하세요. Tipsy 또는 Character.AI에 로그인한 뒤 **내보내기**를 누르세요.

## 데스크톱 Chrome

1. Chrome 111 이상에서 ZIP을 다운로드하고 계속 보관할 폴더에 압축을 푸세요.
2. `chrome://extensions`를 열고 **개발자 모드**를 켜세요. **압축해제된 확장 프로그램을 로드합니다**를 클릭한 뒤 `manifest.json`이 있는 `tipsy-exporter` 폴더를 선택하세요.
3. RoleLeaf를 도구 모음에 고정하고 원본 사이트를 새로고침하세요. 확장 프로그램을 열고 메뉴에서 언어를 선택하세요.

## 캐릭터 내보내기

**최근 대화** 또는 **내 캐릭터**에서 저장할 항목을 선택하고 내보내기를 시작하세요. 완료될 때까지 앱이나 탭을 열어 두세요. 캐릭터마다 별도의 ZIP으로 저장됩니다. 압축을 풀고 `README.html`을 열어 내용을 확인하세요.

캐릭터 백업에는 접근 가능한 저장 설정이 포함되고 대화 내보내기는 현재 대화를 대상으로 합니다. 누락된 항목과 불완전한 기록은 보고서에 표시됩니다. 기기에 저장된 ZIP에 비공개 대화와 이미지가 포함될 수 있으니 공유 시 주의하세요.

Android에서 로그인 상태를 유지하려면 기존 앱 위에 새 버전을 설치하세요. Chrome은 같은 확장 프로그램 폴더의 파일을 교체하고 `chrome://extensions`에서 확장 프로그램을 다시 로드한 뒤 원본 사이트를 새로고침하세요.
