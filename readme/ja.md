# RoleLeaf

[English](../README.md) · [العربية](ar.md) · 日本語 · [한국어](ko.md) · [繁體中文](zh-Hant.md)

RoleLeaf は、Tipsy や Character.AI で取得できるキャラクター情報、画像、会話を端末に保存します。

[ダウンロードとインストール手順](https://quillharbor.github.io/roleleaf-demo/?lang=ja)

## Android

1. Android 8 以降の端末でデモ版の APK をダウンロードします。
2. APK を開きます。求められた場合は、ブラウザーからの不明なアプリのインストールを許可してから戻り、インストールします。
3. RoleLeaf を開き、上部の「⋮」から「言語」を選びます。Tipsy または Character.AI にログインし、「書き出す」をタップします。

## パソコン版 Chrome

1. Chrome 111 以降で ZIP をダウンロードし、保管できる場所に解凍します。
2. `chrome://extensions` を開き、「デベロッパー モード」をオンにします。「パッケージ化されていない拡張機能を読み込む」をクリックし、`manifest.json` が入っている `tipsy-exporter` フォルダーを選びます。
3. RoleLeaf をツールバーに固定し、元のサイトを再読み込みします。拡張機能を開き、メニューから言語を選びます。

## キャラクターのエクスポート

「最近のチャット」または「マイキャラクター」で対象を選び、エクスポートを開始します。完了までアプリやタブを開いておいてください。キャラクターごとに ZIP が保存されます。解凍後に `README.html` を開くと内容を確認できます。

キャラクターのバックアップには取得できる保存済み設定が含まれます。会話のエクスポート対象は現在のチャットです。不足項目や不完全な履歴はレポートに記録されます。保存した ZIP には個人的な会話や画像が含まれる場合があります。

Android を更新する場合は、ログイン状態を保つため上書きインストールします。Chrome 拡張機能の更新時は、同じフォルダー内のファイルを置き換え、`chrome://extensions` で拡張機能を再読み込みし、元のサイトを更新します。
