# RoleLeaf

[English](../README.md) · [العربية](ar.md) · [日本語](ja.md) · [한국어](ko.md) · 繁體中文

RoleLeaf 可將 Tipsy 和 Character.AI 中可取得的角色資料、圖片及對話儲存到你的裝置。

[下載與安裝指南](https://quillharbor.github.io/roleleaf-demo/?lang=zh-Hant)

## Android

1. 在 Android 8 以上版本的裝置下載體驗版 APK。
2. 開啟 APK。若系統提示，允許此瀏覽器安裝未知的應用程式，再返回並確認安裝。
3. 開啟 RoleLeaf，從頂部工具列的「⋮ → 語言」切換語言，登入 Tipsy 或 Character.AI，再點選「匯出」。

## 電腦版 Chrome

1. 使用 Chrome 111 以上版本下載 ZIP，並解壓縮到會長期保留的位置。
2. 開啟 `chrome://extensions` 並啟用「開發人員模式」。點選「載入未封裝項目」，選取內含 `manifest.json` 的 `tipsy-exporter` 資料夾。
3. 將 RoleLeaf 釘選到工具列，重新整理來源網站。開啟擴充功能並從選單切換語言。

## 匯出角色

在「近期對話」或「我的角色」選取要儲存的項目並開始匯出。匯出完成前請保持應用程式或瀏覽器分頁開啟。每個角色會個別儲存為 ZIP。解壓縮後開啟 `README.html` 即可查看內容。

角色備份包含可取得的已儲存設定，對話匯出涵蓋目前對話。缺漏欄位及不完整的記錄會列於報告。匯出檔會儲存在裝置上，可能包含私人對話和圖片，請謹慎分享。

更新 Android 時，覆蓋安裝新版即可保留登入狀態。更新 Chrome 擴充功能時，替換原資料夾中的檔案，在 `chrome://extensions` 重新載入擴充功能，再重新整理來源網站。
